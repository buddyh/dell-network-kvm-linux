# Vendor notice

This is an independent project, unaffiliated with Dell. It contains original Python interoperability code and a wire schema reconstructed from macOS Dell Display and Peripheral Manager (DDPM) metadata.

The implementation was tested against DDPM 2.3.0.1005. Descriptor metadata was also compared with 2.3.0.2004; runtime compatibility with that version is unverified. [Protobuf Objective-C headers](https://github.com/protocolbuffers/protobuf/tree/v31.1/objectivec) informed descriptor interpretation.
